## 📄 About

This repository contains the single-page landing website for Cognify AI, showcasing:

- ✨ All 8 core features
- 🚀 Quick start installation guide
- 📖 Usage examples with CLI commands
- 🛠️ Tech stack information

- **Responsive Design** - Works on desktop, tablet, and mobile
- **Dark/Light Mode** - Toggle with localStorage persistence
- **Self-Contained** - Single HTML file, no external dependencies
- **Modern CSS** - Flexbox/Grid layout, smooth animations
- **Semantic HTML5** - Clean, accessible structure

## 🛠️ Tech

- Pure HTML5, CSS3, and vanilla JavaScript
- No frameworks or external dependencies
- Hosted on GitHub Pages
